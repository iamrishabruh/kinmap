This page never shows a location

No coordinate is in this link, and none is shown on this page. A live location is only ever visible inside the app, to someone signed in as a person the sharer chose. There is no version of this that works in a browser to whoever holds the URL, and that is on purpose — a link that leaked would otherwise leak a person's position.

Live sharing stops on its own

A live session runs for a set time and then ends by itself. The person sharing can also stop it at any moment, and the link stops working immediately when they do. Nobody has to remember to turn it off.
